## ✨ Ключевые возможности

### 📱 Telegram Mini App (Веб-интерфейс)
- **Визуальная лента нагрузки (Workload Calendar)**: интерактивная полоса дней с цветовыми индикаторами загруженности (зеленый/желтый/красный), отображающая количество заданий на каждый день.
- **Интеллектуальная фильтрация**: быстрые вкладки — *Сегодня*, *Завтра*, *2 дня*, *Просроченные* и просмотр всех активных задач с моментальным поиском.
- **Интерактивный просмотрщик фото**: полноэкранный Telegram-style слайдер материалов с поддержкой pinch-to-zoom, жестов смахивания и мгновенным кэшированием.
- **Центр настроек (3 вкладки)**:
  - *Уведомления*: переключение утренних (08:00), дневных (16:00), вечерних (18:00) напоминаний и добавление произвольных кастомных времён (например, `19:30`, `21:00`).
  - *Охват задач*: гибкий выбор, какие дедлайны включать в рассылку (сегодня, завтра, за 2 дня, просроченные).
  - *О боте*: статус подключения к БД, версия Mini App и сброс настроек до рекомендованных.
- **Разграничение прав и аудит**: редактирование и удаление задач автором или администратором с фиксацией истории правок (`last_edited_by`, `last_edited_at`).

### 🤖 Telegram Bot (Aiogram 3)
- **Автономный парсер текста**: быстрое добавление домашних заданий из чатов и личных сообщений на русском и английском языках с распознаванием дней недели.
- **Контекстные уведомления**: умные персонализированные сводки с фильтрацией выполненных задач.
- **Недельный дайджест**: каждое воскресенье в 18:00 рассылает расписание и все задания на предстоящую учебную неделю.
- **Синхронизация профиля**: автоматическая установка кнопки Меню (`WebAppInfo`) и описания бота при запуске.

### ⚡ Высокопроизводительный бэкенд
- **Многоуровневое кэширование фото**: оперативная память (RAM) ➔ локальный диск (`uploads/`) ➔ облачная база. Отдача изображений за 0–2 мс с поддержкой заголовков `ETag` и `Cache-Control`.
- **Оптимизация изображений**: автоматическое выравнивание EXIF-ориентации снимков с мобильных устройств и сжатие больших фото до 90% без потери читаемости рукописного текста.
- **Бесперебойный гибридный режим**: основной бэкенд на **Supabase (PostgreSQL)** с прозрачным резервным переключением на локальный **SQLite (`homework.db`)**.
- **Встроенный Keep-Alive воркер**: предотвращает засыпание бесплатных инстансов на Render.com каждые 5 минут.

## 🏗 Архитектура проекта

Начиная с версии `2.8.2`, исходный код бэкенда разделен на независимые модули внутри пакета `app/`. Корневые файлы проекта сохранены в качестве **обратно-совместимых прокси-модулей**, гарантируя бесшовную работу всех существующих скриптов развертывания, Docker и локальных окружений.

```text
HW_MANAGER/
├── app/                        # Основной пакет приложения
│   ├── api/                    # REST API эндпоинты (FastAPI)
│   │   ├── __init__.py
│   │   └── server.py           # Маршруты Mini App, загрузка фото, статика
│   ├── bot/                    # Логика Telegram-бота (Aiogram 3)
│   │   ├── __init__.py
│   │   └── bot.py              # Хэндлеры, клавиатуры, шаблоны сообщений
│   ├── database/               # Слой работы с базами данных
│   │   ├── __init__.py
│   │   ├── db.py               # SQLite шлюз и адаптер переключения
│   │   └── supabase_db.py      # Клиент Supabase PostgreSQL
│   └── services/               # Вспомогательные сервисы
│       ├── __init__.py
│       ├── parser.py           # Парсер естественного языка для ДЗ
│       └── sync_service.py     # Фоновый сервис синхронизации
│
├── static/                     # Статика фронтенда Mini App
│   ├── index.html              # Одностраничное приложение Mini App
│   ├── style.css               # Стили, адаптивная верстка, анимации
│   └── app.js                  # Клиентская логика, календарь, настройки
│
├── uploads/                    # Каталог локального кэша файлов и фото
├── supabase_schema.sql         # SQL-схема таблиц, индексов и политик RLS
├── run.py                      # Главный запускной файл (FastAPI + Bot + Scheduler)
├── launch_services.py          # Локальный запуск (Cloudflared туннель + Bot)
├── Dockerfile                  # Контейнеризация для продакшена
├── docker-compose.yml          # Запуск мультиконтейнерного стека
├── render.yaml                 # Конфигурация для Render.com
├── Procfile                    # Инструкция процессов для PaaS-хостингов
├── requirements.txt            # Зависимости Python
├── CHANGELOG.md                # История изменений и версий
└── README.md                   # Документация проекта
```

## 🚀 Быстрый старт

### 1. Клонирование и установка зависимостей

```bash
git clone https://github.com/SwagaWaga/HW_MANAGER.git
cd HW_MANAGER

# Создание и активация виртуального окружения
python -m venv .venv
source .venv/bin/activate  # Для Linux/macOS
# .venv\Scripts\activate   # Для Windows

# Установка зависимостей
pip install -r requirements.txt
```

### 2. Настройка переменных окружения

Создайте файл `.env` в корне проекта (или настройте переменные в панели хостинга):

```env
# Telegram Bot Token (получите у @BotFather)
BOT_TOKEN=1234567890:ABCdefGHIjklMNOpqrSTUvwxyz

# Публичный URL вашего бэкенда (для Telegram WebApp)
WEB_APP_URL=https://your-service.onrender.com

# Часовой пояс напоминаний (по умолчанию Asia/Tashkent)
BOT_TIMEZONE=Asia/Tashkent

# Подключение к Supabase (опционально, при отсутствии используется SQLite)
SUPABASE_URL=https://your-project.supabase.co
SUPABASE_KEY=your-supabase-anon-or-service-key

# Секретный ключ для вызова эндпоинтов очистки (опционально)
ADMIN_SECRET_KEY=your-secret-cleanup-key
```

### 3. Запуск

#### Режим совместного сервиса (Рекомендуется для продакшена и Render):
Запускает одновременно FastAPI сервер, Telegram-бота и фоновый планировщик:
```bash
python run.py
```

#### Локальный запуск с Cloudflare Tunnel:
Автоматически поднимает локальный сервер, генерирует публичный HTTPS-туннель через `cloudflared` и запускает бота:
```bash
python launch_services.py
```

#### Запуск через Docker:
```bash
docker build -t hw-manager .
docker run -p 8000:8000 --env-file .env hw-manager
```

## ⚙️ Переменные окружения

| Переменная | Обязательная | Описание | По умолчанию |
| :--- | :---: | :--- | :--- |
| `BOT_TOKEN` | Да | Токен Telegram-бота от `@BotFather` | — |
| `WEB_APP_URL` | Нет | Публичный HTTPS-адрес хостинга Mini App | `https://hw-manager-portal.onrender.com` |
| `BOT_TIMEZONE` | Нет | Часовой пояс для уведомлений и календаря | `Asia/Tashkent` |
| `SUPABASE_URL` | Нет | URL проекта Supabase | — (используется SQLite) |
| `SUPABASE_KEY` | Нет | Ключ доступа API Supabase | — |
| `ADMIN_SECRET_KEY` | Нет | Секретный токен для вызова эндпоинта `/api/tasks/cleanup` | — |
| `PORT` | Нет | Порт веб-сервера | `8000` |
